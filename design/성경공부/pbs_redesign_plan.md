## 1. 기존 구조 vs 신규 구조

### 1.1 기존 구조 (CRUD 폼 방식)

```
[PBS 목록 화면]                    [PBS 등록/수정 화면]
┌──────────────────┐              ┌──────────────────────┐
│ 번호  제목  날짜  │   → 클릭 →   │ 제목 입력            │
│ 1    창조  8/24  │              │ 날짜 선택            │
│ 2    출애굽 8/31 │              │ 성경 구절 선택       │
│ ...              │              │ 성경 본문 표시       │
│ [페이징]        │              │ 내용 입력 (textarea) │
└──────────────────┘              │ 참고자료 (URL/파일)  │
                                  │ [저장] [취소]        │
                                  └──────────────────────┘
```

**문제점:**
- 목록에서 클릭해야만 내용을 볼 수 있음
- 등록 화면이 폼 중심이라 미리보기가 어려움
- 성경 본문과 묵상 내용이 분리되어 있어 흐름이 끊김
- Confluence처럼 "페이지를 작성하면서 내용을 바로 보는" 구조가 아님

### 1.2 신규 구조 (Confluence 페이지 방식)

```
[PBS 페이지 목록]                  [PBS 페이지 작성/조회]
┌──────────────────┐              ┌──────────────────────────────┐
│ 📄 창세기 1장    │   → 클릭 →   │ 📄 창세기 1장 묵상          │
│    하나님의 창조  │              │                              │
│ 📄 출애굽기 3장  │              │ 📖 창세기 1:1-3 (새번역)     │
│    모세의 부름    │              │ "태초에 하나님이 천지를..."  │
│ 📄 시편 23편      │              │                              │
│    여호와는 나의  │              │ ✍️ 묵상 내용 (에디터)       │
│    목자시니       │              │ "하나님께서 말씀으로..."     │
│                  │              │                              │
│ [+ 새 페이지]     │              │ 📎 참고자료                 │
│ [검색]           │              │ 🔗 URL · 🖼 이미지 · 📄 문서 │
└──────────────────┘              │                              │
                                  │ [수정] [공유] [히스토리]    │
                                  └──────────────────────────────┘
```

## 2. 신규 화면 구성

### 2.1 PBS 페이지 목록 (Page List)

**개념:** Confluence의 "페이지 트리"와 유사 — 카드형 목록 + 검색 + 새 페이지

```
┌─────────────────────────────────────────────────────────────┐
│  ☰  성경공부 (P.B.S)                    🔍 검색  [+ 새 페이지] │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📄 창세기 1장 — 하나님의 창조                              │
│  성경: 창세기 1:1-3 · 2026.08.24 · 관찰/해석/적용           │
│  ───────────────────────────────────────────────────────     │
│  📄 출애굽기 3장 — 모세의 부름                               │
│  성경: 출애굽기3:1-10 · 2026.08.31 · 관찰/해석/적용          │
│  ───────────────────────────────────────────────────────     │
│  📄 시편 23편 — 여호와는 나의 목자시니                       │
│  성경: 시편23:1-6 · 2026.09.07 · 관찰/해석/적용              │
│  ───────────────────────────────────────────────────────     │
│  📄 요한복음 1장 — 말씀이 육신이 되어                        │
│  성경: 요한복음1:1-14 · 2026.09.14 · 관찰/해석/적용          │
│                                                             │
│  ‹ 1 2 3 4 ›                                                │
└─────────────────────────────────────────────────────────────┘
```

**주요 기능:**
- 카드형 페이지 목록 (제목, 성경구절, 날짜, 요약)
- 검색 (제목/성경구절/내용)
- "새 페이지" 버튼 → 빈 페이지 작성 화면으로 이동
- 각 페이지 카드 클릭 → 페이지 조회 화면으로 이동
- 페이지 카드 우측 ⋯ 메뉴: 수정, 복사, 삭제

## 3. 핵심 변경 사항

| 항목 | 기존 | 신규 (Confluence 스타일) |
|------|------|------------------------|
| **목록** | 테이블 형태 (번호/제목/날짜/상태) | 카드형 페이지 목록 (제목/성경구절/날짜/요약) |
| **등록** | 별도 등록 화면 (폼 중심) | 페이지 작성 화면에서 바로 내용 작성 (인라인 편집) |
| **조회** | 목록 클릭 → 상세 팝업 or 별도 화면 | 페이지 자체가 조회 화면 (읽기 모드) |
| **수정** | 등록 화면 재활용 | 조회 화면에서 인라인 편집 모드 전환 |
| **성경 본문** | 고정 표시 (3 탭) | 성경 구절 선택 시 자동 조회 + 미리보기 |
| **내용 구조** | 단일 textarea | 관찰/해석/적용 3개 RichText 에디터 |
| **참고자료** | 별도 영역 | 페이지 내 인라인 첨부 |
| **수정 이력** | 없음 | 히스토리 화면 (버전별 조회/복원) |
| **미리보기** | 없음 | 편집 중 미리보기 모드 |
| **내비게이션** | 등록↔목록 이동 | 목록↔페이지 이동 (이력 접근) |

## 4. 데이터 모델 변경

### 4.1 pbs 테이블 수정

```sql
-- 기존 pbs 테이블에 컬럼 추가
ALTER TABLE pbs ADD COLUMN page_slug VARCHAR(200) NULL COMMENT '페이지 슬러그 (URL용)';
ALTER TABLE pbs ADD COLUMN observation TEXT NULL COMMENT '관찰 내용 (RichText HTML)';
ALTER TABLE pbs ADD COLUMN interpretation TEXT NULL COMMENT '해석 내용 (RichText HTML)';
ALTER TABLE pbs ADD COLUMN application TEXT NULL COMMENT '적용 내용 (RichText HTML)';
ALTER TABLE pbs ADD COLUMN version INT NOT NULL DEFAULT 1 COMMENT '페이지 버전';
```

### 4.2 pbs_history 테이블 신규

```sql
CREATE TABLE pbs_history (
    history_id    BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '이력 ID (PK)',
    pbs_id        BIGINT       NOT NULL                COMMENT 'PBS ID (FK)',
    version       INT          NOT NULL                COMMENT '버전 번호',
    title         VARCHAR(200) NOT NULL                COMMENT '제목 (스냅샷)',
    bible_ref     VARCHAR(100) NULL                    COMMENT '성경 구절 (스냅샷)',
    bible_text    TEXT         NULL                    COMMENT '성경 본문 (스냅샷)',
    observation  TEXT         NULL                    COMMENT '관찰 (스냅샷)',
    interpretation TEXT      NULL                    COMMENT '해석 (스냅샷)',
    application  TEXT         NULL                    COMMENT '적용 (스냅샷)',
    edited_by     BIGINT       NOT NULL                COMMENT '수정자 ID (FK)',
    edited_at     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '수정일시',
    PRIMARY KEY (history_id),
    KEY fk_pbs_history_pbs (pbs_id),
    CONSTRAINT fk_pbs_history_pbs FOREIGN KEY (pbs_id) REFERENCES pbs (pbs_id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='PBS 페이지 수정 이력';
```

## 5. API 엔드포인트 변경

| Method | 기존 | 신규 | 설명 |
|--------|------|------|------|
| GET | /api/pbs | /api/pbs/pages | 페이지 목록 (카드형) |
| GET | /api/pbs/{id} | /api/pbs/pages/{slug} | 페이지 조회 (슬러그) |
| POST | /api/pbs | /api/pbs/pages | 새 페이지 작성 |
| PUT | /api/pbs/{id} | /api/pbs/pages/{id} | 페이지 수정 (인라인 편집) |
| DELETE | /api/pbs/{id} | /api/pbs/pages/{id} | 페이지 삭제 |
| — | 없음 | GET /api/pbs/pages/{id}/history | 페이지 수정 이력 조회 |
| — | 없음 | POST /api/pbs/pages/{id}/restore/{version} | 특정 버전으로 복원 |

- ⋯ 메뉴: 수정, 복사, 삭제

### 7.3 페이지 조회/편집 전환

- **조회 모드:** 읽기 전용, 성경 본문 표시, 관찰/해석/적용 카드
- **편집 모드:** "수정" 클릭 시 같은 화면에서 인라인 편집 (화면 전환 없음)
- 성경 구절 변경 시 자동으로 본문 재조회
- RichText 에디터 (Tiptap — holylifeView에 이미 있음)

### 7.4 반응형

- **데스크톱:** 사이드바 + 페이지 영역
- **태블릿:** 사이드바 숨김, 페이지 영역 전체
- **모바일:** 상단 헤더 + 페이지 영역, 하단 네비
