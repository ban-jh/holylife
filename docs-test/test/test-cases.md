## 4. 이슈 해결 내역

### ISSUE-01: QT Daily API source 파라미터 (해결됨)
- **원인:** 오늘 날짜의 QT 데이터가 DB에 없어서 400 반환 (크롤링 데이터 마지막: 10월 17일)
- **결론:** API 동작은 정상 (defaultValue="duranno" 설정되어 있음). 데이터 없을 시 400은 정상 동작.
- **상태:** 해결됨 (테스트 케이스 수정)

### ISSUE-02: 백엔드 API별 권한 제어 미구현 (해결됨)
- **원인:** 백엔드가 인증(Authentication)만 체크하고 권한(Authorization)별 API 접근 제어 없음
- **해결:** RoleAuthorizationFilter 추가 — 시스템 관리 API는 SYS_ADMIN만 접근, 콘텐츠 API는 모든 인증 사용자 허용
- **예외:** GET /api/roles (권한 드롭다운용), GET /api/menus/tree (사이드바 메뉴용)은 모든 사용자 허용
- **상태:** 해결됨

### ISSUE-03: Google Maps API 키 미설정 (제외)
- **상태:** 사용자 요청으로 테스트에서 제외
