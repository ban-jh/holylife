## 사전 준비물

- 신용카드 또는 직불카드 (신용카드와 동일 기능, PIN/선불/가상카드 불가)
- 휴대폰 번호 (SMS 인증용)
- 이메일 주소
- 영문 주소 (네이버에서 "영문주소" 검색)

---

## 가입 절차

### Step 1: Oracle Cloud Free Tier 페이지 접속

1. https://www.oracle.com/kr/cloud/free/ 접속
2. "무료로 시작하기" 버튼 클릭

### Step 2: 계정 정보 입력

1. **국가 선택:** 대한민국
2. **이름/성:** 영문으로 입력
3. **이메일:** 사용할 이메일 주소 입력
4. "내 전자메일 확인" 버튼 클릭 → 이메일로 인증 메일 발송

### Step 3: 이메일 인증

1. 받은 메일에서 인증 링크 클릭
2. 같은 브라우저에서 열어야 이어서 진행됨

### Step 4: 추가 정보 입력

1. **비밀번호:** 영문 대소문자, 숫자, 특수문자 포함 8자 이상
2. **클라우드 계정 이름:** 로그인 시 사용할 계정명 (변경 불가)
3. **홈 리전 선택:** 중요 — 아래 참조

> **홈 리전 선택 가이드:**
> - 서울(Seoul): 수요가 많아 VM 생성이 어려울 수 있음 ("Out of capacity" 오류)
> - 춘천(Chuncheon): 상대적으로 여유로움
> - 일본 오사카/도쿄: 한국과 지리적으로 가까워 지연 적음
> - 홈 리전은 최초 설정 후 변경 불가이므로 신중하게 선택

### Step 5: 주소 및 연락처 입력

1. **주소:** 영문 주소로 입력 (네이버 "영문주소" 검색)
2. **휴대폰 번호:** SMS 인증 코드 수신용
3. "계속" 버튼 클릭

### Step 6: 신용카드 등록

1. "Add Credit Card Details" 버튼 클릭
2. 카드 번호, 만료일, CVV 입력
3. 인증을 위해 소액(약 $1)이 결제되었다가 바로 취소됨
4. 문자로 결제/취소 알림이 오면 정상

> 신용카드 청구되지 않음 — 본인 확인용이며, 유료 계정으로 업그레이드하지 않는 한 요금 청구 없음

### Step 7: 약관 동의 및 가입 완료

1. Oracle Cloud 서비스 약관에 동의
2. "무료 계정 시작" 버튼 클릭
3. 계정 생성 중 (약 1분) → 로그인 페이지로 이동

### Step 8: 로그인 및 MFA 설정

1. 생성한 계정으로 로그인
2. 첫 로그인 시 2단계 인증(MFA) 설정 요청
3. Oracle Mobile Authenticator 앱 설치 또는 다른 인증 방식 선택

### Step 9: OCI 콘솔 접속

1. 로그인 완료 → Oracle Cloud Infrastructure(OCI) 콘솔 접속
2. 이제 VM 인스턴스, 데이터베이스 등 상시 무료 서비스 사용 가능

---

## 가입 후 다음 단계 (holylife 배포)

가입 완료 후 다음 작업을 진행:

1. **ARM VM 인스턴스 생성** (Ubuntu, 2 OCPU, 12GB RAM)
2. **SSH 키 설정 및 접속**
3. **서버 환경 구성** (Java 17, MariaDB, Nginx 설치)
4. **holylife 배포** (JAR, Vue 빌드 파일, DB 이전)
5. **도메인/SSL 설정** (Let's Encrypt 무료 인증서)

## Oracle Cloud Free Tier 무료 제공 내용

| 항목 | 무료 제공 내용 |
|------|---------------|
| ARM 컴퓨트 | 최대 2 OCPU, 12GB RAM (1개 VM 또는 2개 VM으로 분할) |
| AMD 컴퓨트 | 1/8 OCPU, 1GB RAM x 2대 (버스트 가능) |
| 스토리지 | 블록 볼륨 200GB |
| 네트워크 | 아웃바운드 10TB/월, 로드밸런서 1개 |
| 데이터베이스 | Autonomous Database 2개 (각 1 OCPU, 20GB) |
| 유효 기간 | 영구 무료 (Always Free) — 시간 제한 없음 |
| 슬립/대기 | 없음 (24시간 운영 가능) |
| 신용카드 | 가입 시 필요 (청구되지 않음) |

## holylife 프로젝트 적용 방안

| 구성 요소 | Oracle Cloud 서비스 | 사양 |
|-----------|---------------------|------|
| Spring Boot 백엔드 | ARM Ampere A1 VM (Ubuntu) | 2 OCPU, 12GB RAM |
| MariaDB | VM 내부에 직접 설치 | 200GB 스토리지 |
| Vue 프론트엔드 | VM 내부 Nginx | 정적 파일 서빙 |
| 도메인/SSL | Oracle 로드밸런서 + Let's Encrypt | 무료 |

## 주의사항

| 항목 | 내용 |
|------|------|
| 중복 가입 | 1인 1계정만 허용 (이메일/전화번호/카드 조합으로 확인) |
| 30일 유휴 계정 | 30일 이상 미사용 시 계정 일시 중단 가능 — 주기적 로그인 필요 |
| $300 크레딧 | 30일 후 소멸, 상시 무료 서비스는 계속 사용 가능 |
| 유료 업그레이드 | 하지 않는 한 과금 없음 |
| 서울 리전 | "Out of capacity" 오류 빈번 — 춘천 또는 일본 리전 권장 |
